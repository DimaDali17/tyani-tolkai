# Тяни-Толкай — 3D

**▶ Открыть: https://dimadali17.github.io/tyani-tolkai/**

Тяни-Толкай из «Айболита» — двуголовый жираф, которого сшила Эля. А мы его просто оживили: сфотографировали игрушку с 8 ракурсов и сделали по фото интерактивную 3D-модель.

**Что умеет** (подсказок на экране нет — пробуй сам)
- крутить камеру мышкой/пальцем, приближать колёсиком или щипком;
- нажми на **ногу** — брыкается (колено сгибается), на **голову** — оглядывается и фыркает,
  на **шею** — кланяется, на **гриву** — встряхивает, на **ухо** — дёргает, на **рожки** — пружинят,
  на **бока** — щекотно;

Всё в одном файле `index.html`: three.js подгружается с CDN, туловище и шеи — гладкие «плюшевые» поверхности (SDF + marching cubes), звуки фырканья синтезируются прямо в браузере.
